**Unityでプロジェクトにインポート**<br>

<details><summary>Addressablesのインポート (クリックで展開)</summary>

ウィンドウ -> アセット管理 -> Addressables -> グループ<br>
Create Addressables Settingsをクリックして下さい。<br>
Legacy Bundles Detectedの警告が出たら、Ignoreをクリックして下さい。<br>
Addressables GroupsのDefault Local Group (Default)に<br>
Assets\Resources2\dat<br>
Assets\Resources2\prefab<br>
を追加して下さい。<br>
</details><br>

<details><summary>TextMesh Proのインポート (クリックで展開)</summary>

ウィンドウ -> TextMeshPro -> TMP 基本リソースのインポート<br>
インポートをクリックして下さい。<br>
</details><br>

<details><summary>TexturePackerのインポート (クリックで展開)</summary>

アセットストア [TexturePacker Importer](https://assetstore.unity.com/packages/tools/sprite-management/texturepacker-importer-16641)<br>
パッケージマネージャー -> マイアセット -> TexturePacker Importer<br>
インポートをクリックして下さい。<br>
</details><br>

<details><summary>DOTweenのインポート (クリックで展開)</summary>

アセットストア [DOTween (HOTween v2)](https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676)<br>
パッケージマネージャー -> マイアセット -> DOTween<br>
インポートをクリックして下さい。<br>
</details><br>

<details><summary>Sunny Landのインポート (クリックで展開)</summary>

アセットストア [Sunny Land](https://assetstore.unity.com/packages/2d/characters/sunny-land-103349)<br>
パッケージマネージャー -> マイアセット -> Sunny Land<br>
インポートをクリックして下さい。<br>
Assets/SunnyLand Artwork/Environment/Tileset/Main PaletteをSunnyLandTilePalletに名前を変更して下さい。<br>
</details><br>
