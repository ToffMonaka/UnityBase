Unityでプロジェクトにインポート<br>
AssetsにAddressableAssetsDataを追加<br>
ウィンドウ -> アセット管理 -> Addressables -> グループ<br>
Create Addressables Settingsをクリックして下さい。<br>
Legacy Bundles Detectedの警告が出たら、Ignoreをクリックして下さい。<br>
Addressables GroupsのDefault Local Group (Default)に<br>
Assets\Resources2\dat<br>
Assets\Resources2\prefab<br>
を追加して下さい。<br>

AssetsにTextMesh Proを追加<br>
ウィンドウ -> TextMeshPro -> TMP 基本リソースのインポート<br>
インポートをクリックして下さい。<br>

Assetsにcodeandweb.comを追加<br>
パッケージマネージャー -> マイアセット -> TexturePacker Importer<br>
インポートをクリックして下さい。<br>

PluginsにDemigiantを追加<br>
パッケージマネージャー -> マイアセット -> DOTween<br>
インポートをクリックして下さい。<br>
